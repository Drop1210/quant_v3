# QuantV3 — A股量化研究与交易平台（个人版）

按"研究闭环优先"原则重建的量化系统，架构参考微软 Qlib 五层设计：

```
data(数据) → factors(因子) → alpha(信号合成) → portfolio(组合) → backtest(回测)
                                   ↓
                        dashboard(分析报告 + 手机网页) → push(微信推送)
```

## 阶段进度

- [x] 阶段 1：数据引擎（点对点成分股 + 增量更新 + 多源容错）
- [x] 阶段 2：因子层（Alpha158 子集 + Barra 中性化 + 四关检验）

## 每日使用

```
python daily_run.py --update    # 更新数据 + 选股 + 报告 + 推送
```

每天自动记录选股，满 5 个交易日后自动统计实际表现（平均收益/跑赢指数），
推送到微信并在手机网页展示（选股跟踪周报）。

手机版部署步骤见 `deploy/README_上传说明.md`。
