# QuantV3 — A股量化研究与交易平台（个人版）

按"研究闭环优先"原则重建的量化系统，架构参考微软 Qlib 五层设计：

```
data(数据) → factors(因子) → alpha(信号合成) → portfolio(组合) → backtest(回测)
                                   ↓
                        dashboard(分析报告 + 手机网页) → push(微信推送)
```

## 阶段进度

- [x] 阶段 1：数据引擎（点对点成分股 + 增量更新 + 多源容错）
- [ ] 阶段 2：因子层（Alpha158 子集 + Barra 中性化 + 四关检验）
- [ ] 阶段 3：组合层 + 回测层（30~50 只 + 涨跌停约束）
- [ ] 阶段 4：分析报告 + 微信推送 + 手机网页
- [ ] 阶段 5：GitHub Actions 定时 + 试运行
